# Contributing to PromptCourt

Thank you for your interest in contributing to PromptCourt!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/1997agarwal/PromptCourt.git
   cd PromptCourt
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Run tests:
   ```bash
   npm run test
   ```

## Pull Request Guidelines

- Ensure tests pass with `npm run test` and the project builds cleanly with `npm run build`.
- Maintain clean TypeScript types without `any`.
- Keep the UI compliant with the 2026 Light Modern design tokens.
- Add test coverage for any new mutations or game rules.
